# refs/

Video di riferimento per ritmo e transizioni (non versionati). Per ognuno:

```sh
node apps/motion/scripts/refs.mjs apps/motion/refs/esempio.mp4          # contact sheet + tagli
node apps/motion/scripts/refs.mjs apps/motion/refs/esempio.mp4 --fps 8 --from 3 --to 6   # un passaggio da vicino
```

Poi chiedi a Claude di leggere `refs/esempio-sheet.jpg` e di descrivere: durata media delle inquadrature, tipi di
transizione (whip, maschere, zoom-through, match cut), come entra il testo. Scrivi qui sotto le note che contano, così
restano anche per le sessioni successive.
